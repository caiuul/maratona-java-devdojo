# Maratona Java - DevDojo 🚀

Repositório dedicado ao meu aprendizado de Java Core, acompanhando o curso **Maratona Java** do DevDojo. Aqui documento minha evolução e a implementação de conceitos fundamentais e avançados da linguagem.

## 🛠 Tecnologias e Conceitos Estudados

### Java Core
* **Orientação a Objetos:** Classes, métodos, herança, polimorfismo e interfaces.
* **Tratamento de Exceções:** Blocos try-catch, multi-catch e exceções customizadas.
* **Wrappers e Strings:** Manipulação avançada de tipos e performance.
* **I/O (Entrada e Saída):** File, FileReader, FileWriter, BufferedWriter e leitura de arquivos.

### Coleções (Collections)
* Uso de `List`, `ArrayList`, `Set`, `Map`.
* Ordenação de objetos com `Comparable` e `Comparator`.
* Busca binária em coleções com `binarySearch`.

## 📁 Estrutura do Projeto

O projeto é organizado por pacotes seguindo a evolução das aulas:
* `Vio.test`: Testes de manipulação de arquivos.
* `Ycolecoes`: Estudos sobre estruturas de dados e ordenação.
* `Npolimorfismo`: Exemplos práticos de métodos polimórficos.
